# Tauri Music App
# Aplicación para la gestión de colecciones de canciones
## App contruida usando Tauri + Vanilla TS + Vite + Rust + SQLite
## Descripción
Aplicación de escritorio local-first para gestionar y reproducir una colección de música almacenada en carpetas locales.
Permite gestionar una colección de canciones almacenadas en local en una o varias carpetas accesibles por la aplicación. 
Los archivos de música pueden estar en distintos formatos, como MP3, FLAC, OGG, WAV, M4A, etc.

## Funcionalidades principales
1. Gestión de la colección de canciones.
2. Gestión de metadatos asociados a las colecciones y las canciones.
2. Gestión de listas de música.
3. Reproducción de listas de música.

Los archivos de música se mantienen sin cambios en el disco. Todos los metadatos, tanto los propios de las canciones como los nuevos que se creen con la aplicación, se guardan en la base de datos.
